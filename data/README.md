# Input data

Download `DataCoSupplyChainDataset.csv` from the permanent public DataCite/Mendeley
record:

<https://data.mendeley.com/datasets/8gx2fvg2k6/3>

Place the file in this directory. The raw file is intentionally excluded from the
Git repository because it is distributed by the data host and may change its
licensing or download packaging. The runner checks the required column names when
it starts and records the input path in `logs/run_metadata.json`.
